# car-shop
Small car webshop created for the university course "Web Software Development". The project focused on learning static web technologies: HTML, CSS and JS on frontend and Node.js with Express.js on backend.

> [!NOTE]
> This project will not receive further updates

## Setup

- Clone or download repository
- Open the project folder in terminal
- Install npm dependencies: `npm install`
- Start server: `node server.js`
- Open `https://localhost:3000` in your browser

> [!NOTE]
> If port 3000 is unavailable try changing variable port in server.js
